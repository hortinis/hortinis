# Hortinis UI exploration prototypes

This directory retains the editable discussion prototypes used while defining the Hortinis product experience. They are not production screens, implementation authorization, or acceptance-test evidence. Sample interface copy may be in French because the prototypes were prepared for a French-language design discussion; repository specifications remain in English.

## Retained prototypes

| Prototype | Focus |
| --- | --- |
| [Home directions A-C](home-directions.html) | Early alternatives for the home-screen hierarchy and navigation. |
| [Place panels](place-panels.html) | Place-grouped work presentation explored after the initial home directions. |
| [Weather and time](weather-time-fr.html) | Compact weather and period-control alternatives. |
| [Compact context](compact-context-fr.html) | Accepted starting direction M for garden context, attention, place groups, weather, period, and bottom navigation. |
| [Recording test](recording-test-fr.html) | Early direct-recording entry and target-selection alternatives. |
| [Stable completion](stable-completion-fr.html) | Provisional direction O for stable completed rows, compact feedback, Details, and Undo. |
| [Quick recording](quick-recording.html) | English type-first quick-recording exploration retained in the repository. |
| [Quick recording, French discussion version](quick-recording-fr.html) | French discussion variant of the type-first quick-recording flow. |
| [Selection and planning](selection-planning-fr.html) | Time-aware selection and planning exploration. |
| [Garden planning flow](garden-planning-flow-fr.html) | More detailed planning and garden-layout exploration; the layout remains optional. |
| [Global application journey](global-journey-fr.html) | First opening, local start, garden overview and switching, synchronization, server changes, draft abandonment, and optional exclusions. |
| [Desktop home](desktop-home-fr.html) | Desktop adaptation of the selected-garden home and global navigation. |
| [Palette](hortinis-palette.html) | Color and surface reference used by the discussion prototypes. |

The product decisions and unresolved questions represented by these prototypes are recorded in [the home-screen specification](../../docs/product/home-screen-specification.md), [functional decisions](../../docs/product/functional-decisions.md), and [open questions](../../docs/product/open-questions.md). When a prototype and a written specification differ, the written specification is authoritative.
