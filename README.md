# Hortinis

Hortinis is an offline-first, self-hostable garden-management application intended to preserve garden history and provide explainable decision support.

The project is currently in the technical-foundation stage. It includes an empty Spring Boot synchronization-service scaffold and an Angular PWA scaffold; production and V0 business features have not been implemented.
