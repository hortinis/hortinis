# Hortinis

Hortinis is an offline-first, self-hostable garden-management application intended to preserve garden history and provide explainable decision support.

The project is currently in the technical-foundation stage. It includes a Spring Boot technical synchronization service and an Angular PWA with IndexedDB persistence, outbox-based synchronization, and bounded recovery; production and V0 business features have not been implemented.
