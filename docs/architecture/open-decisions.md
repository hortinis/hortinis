# Open technical decisions

The following choices are deliberately unresolved:

- programming languages and runtimes;
- web framework and local persistence mechanism;
- service framework and API transport;
- database engine and migration tooling;
- synchronization algorithm and conflict policy;
- identity and access mechanism;
- object-storage mechanism;
- build, test, packaging, and workspace tooling;
- container images and orchestration approach;
- observability stack;
- format, transport, update cadence, and integrity checks for plant reference data.

Each selection should be captured in a decision record with context, alternatives, consequences, migration impact, and validation criteria.
